# 🩷 Flufi

**Flufi es la compañera de Pitri.** Tiene una carita en una pantalla a color, con ojitos
que parpadean, pestañas, **rulos rubios** con un **moño rosa** 🎀 en la frente y **labios rojos de diva** 💋.

La armamos entre Sofia y su papa, de a poquito, como hicimos con Pitri.

```
   @@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@   ← rulos rubios
  @@  @@  @@  @@  @@  @@  @@  @@  @@  @@
        \ | /            \ | /
         \|/              \|/
       ████████        ████████
       ████████        ████████      ← los ojitos de Flufi, con pestañas
       ████████        ████████
       ████████        ████████

                  ▄▀▄▀▄
                  ▀███▀             ← labios rojos de diva
```

## ✨ Que sabe hacer Flufi

| Cuando… | Flufi… |
|---|---|
| Se prende | Dice **"¡Hola Sofi!"** y **"Soy Flufi"**, bien grande |
| Se esta conectando al WiFi | Su cara se aleja y al costado aparecen unas **ondas** que se encienden de a una |
| Se conecta | Dice **"Tengo wifi!"** |
| Sabe la hora | Saluda segun el momento del dia: **"¡Buen dia!"**, **"¡Buenas tardes!"** o **"¡Buenas noches!"** |
| Termina de arrancar | Saluda: se sorprende y se pone contenta, con el LED en **arco iris** 🌈 |
| Esta tranquila (modo Normal) | Juega con sus emociones, y el **LED de la placa** se prende del color de cada una |
| Esta en modo **Animales** | Hace de animal: coneja, unicornio, ratoncita, mariposa o zorrita |
| Esta en modo **Fantasia** | Hace de personaje de cuento: hada, princesa, sirena, dragoncita o caperucita |
| Esta en modo **Ejercicio** | Hace deporte: patina, baila, juega al futbol, anda en bici o levanta pesas |
| Cada 5 minutos en punto (x:00, x:05, x:10...) | Su cara se aleja y muestra la **hora** al costado |
| Cada 15 minutos en punto (x:00, x:15, x:30, x:45) | Muestra la **temperatura** y la **presion del aire** al costado |
| Se conecta **Pitri** (u otro de la familia) | Lo saluda: **"¡Hola Pitri!"** |
| Pitri le manda un **beso** | Ojos de corazon, corazoncitos y **"¡Un beso de Pitri!"** 😍 |
| Cada tanto, con Pitri conectado | **Charlan** por turnos o **juegan juntos** (ver [docs/FAMILIA.md](docs/FAMILIA.md)) |
| Cada media hora (x:00 y x:30) | Cuenta **el tiempo de afuera**: si esta soleado, nublado, si llueve, y si hace frio o calor ☀️☁️🌧️ |
| Aprietan el **boton A** | Abre el **menu** |

| 😵‍💫 Mareada | Ojos en espiral que giran | blanco |
| 😍 Enamorada | Ojos de corazon y corazoncitos que suben | rojo |

Flufi hace de animal, pero siempre con **sus ojos, sus pestañas y sus labios rojos**. Los
animales no tienen rulos: en su lugar llevan sus orejas, su cuerno o sus antenas.

| Animal | Que se le agrega | Que hace | LED |
|---|---|---|---|
| 🐰 Coneja | Orejas largas (una se dobla), naricita de corazon, bigotes y dientitos | Olfatea y da saltitos ("Hop!") | blanco |
| 🦄 Unicornio | Crin de **arco iris** en vez de los rulos y un cuerno dorado | Flota entre estrellitas ("¡Magia!") | arco iris |
| 🐭 Ratoncita | Orejas redondas grandes, naricita y bigotes | Olfatea y aparece un quesito ("¡Queso!") | amarillo |
| 🦋 Mariposa | Alas de colores y antenitas | Vuela aleteando ("¡Fiu!") y guiña un ojo | violeta |
| 🦊 Zorrita | Orejas en punta, cachetes blancos y naricita | Mira picara y mueve la cola ("Je je!") | naranja |

| Deporte | Que se le agrega | Que hace | LED |

### El menu

| Boton | Que hace |
|---|---|
| **A** | Abre el menu y elige la opcion marcada |
| **B** | Pasa a la opcion siguiente |
| **BOOT** (el de la placa) | Vuelve atras |

| Opcion | Que hay adentro |
|---|---|
| **Modo** | **Normal** (emociones), **Animales**, **Fantasia** o **Ejercicio**. El modo de ahora tiene un puntito |
| **Comer** | 🥐 Medialuna, 🧁 Muffin o 🍩 Dona, con su dibujo |
| **Tomar** | 🍵 Te, 🍓 Licuado o 🥤 Gaseosa, con su dibujo |
| **Hora** | La hora grande, el dia y la fecha |
| **Sensor** | La temperatura y la presion del aire |
| **Clima** | El tiempo de afuera, con su dibujo |
| **Familia** | Elegis a alguien de la familia (los que estan conectados) y que hacerle: **Beso**, **Cosquis**, **Convidar**, **Charlar** o **Jugar**. Ver [docs/FAMILIA.md](docs/FAMILIA.md) |
| **Salir** | Vuelve a la cara de Flufi |

Flufi puede comer 3 veces y tomar 3 veces por hora. Si le dan mas, dice **"No, gracias!
Estoy llena"**. No le pasa nada si no come: Flufi nunca muere. Si nadie toca nada por un
rato, el menu se cierra solo.

## 🧩 De que esta hecha Flufi

Usa el mismo hardware del proyecto **color1.44**:

| Parte | Para que sirve |
|---|---|
| **ESP32-C3** (la placa) | Es el **cerebro**: una computadora chiquita que ejecuta el programa |
| **Pantalla TFT 1.44" a color** (128×128) | Es la **cara**: ahi se dibujan los ojos |
| **Sensor BMP280** | Siente la **temperatura** y la **presion del aire** |
| **3 botones** (A, B y BOOT) | Para manejar el **menu** |
| **LED de colores** de la placa | Se prende del color de cada emocion |

Las conexiones de cada cable estan en
[components/board_config/include/board_config.h](components/board_config/include/board_config.h).

## 🎛️ Cambia como es Flufi

En [main/flufi_config.h](main/flufi_config.h) se pueden cambiar los colores y el parpadeo:

```c
#define COLOR_OJOS      COLOR(120, 210, 255)   // celeste
#define COLOR_PESTANAS  COLOR(255, 120, 190)   // rosa
#define COLOR_BOCA      COLOR(225, 20, 50)     // rojo lapiz labial
```

Cada color se arma con tres numeros de 0 a 255: **cuanto rojo, cuanto verde y cuanto
azul**. Por ejemplo, `COLOR(255, 0, 0)` es rojo, `COLOR(255, 255, 0)` es amarillo y
`COLOR(180, 100, 255)` es violeta.

Ahi tambien estan los mensajes del saludo, por ejemplo:

```c
#define MENSAJE_ARRANQUE        "¡Hola\nSofi!"
#define MENSAJE_ARRANQUE_2      "Soy\nFlufi"
```

Y en [components/eyes/eyes.c](components/eyes/eyes.c), arriba de todo, esta la forma de
los ojos (ancho, alto, que tan redondos son, que tan separados estan) y **el color del
LED para cada emocion** y el **color de los rulos** (`COLOR_PELO`), por ejemplo:

```c
#define LED_CONTENTA   LED(255, 110, 0)     // naranja
#define LED_ENAMORADA  LED(255, 0, 0)       // rojo
```

## 📶 WiFi

El nombre y la contraseña de la red WiFi son un **secreto de la casa**, asi que no se suben
al repo:

1. Copia `components/wifi/wifi_secretos.ejemplo.h` en la misma carpeta con el nombre
   `wifi_secretos.h`.
2. En la copia, completa `WIFI_NOMBRE_RED` y `WIFI_CONTRASENA`.

`wifi_secretos.h` esta en el `.gitignore`: se queda en la compu y nunca se sube. Si no esta,
Flufi funciona igual, sin WiFi. Con WiFi, Flufi saca la hora de internet (la zona horaria
esta en `main/flufi_config.h`).

## ☀️ El tiempo de afuera

Flufi saca el tiempo de internet, de **Open-Meteo** (es gratis y no hace falta registrarse).
Cada media hora se aleja y cuenta como esta afuera, con un dibujo que se mueve:

| Tiempo | Dibujo | LED |
|---|---|---|
| Soleado (de noche: despejado) | Sol con rayos que giran (de noche, luna y estrellitas) | amarillo (de noche, azul) |
| Sol y nubes | Sol asomando detras de una nube | amarillo |
| Nublado / neblina | Nubes / rayas de niebla que se mueven | gris |
| Llueve | Nube con gotas que caen | azul |
| Tormenta | Nube oscura, gotas y un rayo que titila | violeta |
| Nieva | Nube con copitos | blanco |

Abajo dice la temperatura y, si hace **14 grados o menos**, "¡Frio!" (y entrecierra los ojitos);
si hace **27 o mas**, "¡Calor!". Esos numeros estan arriba de todo en
[components/eyes/clima.c](components/eyes/clima.c).

Para saber el tiempo, Flufi necesita saber **en que zona estamos**, y eso es un dato privado:

1. Copia `components/pronostico/clima_secretos.ejemplo.h` en la misma carpeta con el nombre
   `clima_secretos.h`.
2. Completa `CLIMA_LATITUD` y `CLIMA_LONGITUD` con los del **barrio** (no hace falta la casa
   exacta). En Google Maps: click derecho en el mapa y aparecen los dos numeros.

`clima_secretos.h` esta en el `.gitignore`: no se sube nunca.
